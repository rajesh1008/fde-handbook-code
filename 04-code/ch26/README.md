# Chapter 26 lab: evals built with the customer's experts

Deterministic stand-in. Every number is generated by `world.py` from fixed hashes; no claims data, no model calls.
It reproduces the shape of the Caldwell story (Northlight's 91% becoming 68% on Anne Kessler's gold set) so that
each method in the chapter can be run, broken and repaired.

| script | listing | what it shows |
|---|---|---|
| vendor_vs_customer.py | 26.1 | the four steps from Northlight's number to Caldwell's |
| goldset_build.py | 26.2 | the stratified draw, the 14-day rule on coded values, the expert-hours budget |
| annotation.py | 26.3 | kappa per field over two calibration rounds; adjudication with reason codes |
| judge_validation.py | 26.4 | injected failure: a judge that agrees with the model and disagrees with Anne |
| regression_gate.py | 26.5 | Caldwell's per-customer gate on two candidates |
| oversight.py | 26.6 | the oversight profile on the gold set, threshold set on one half, checked on the other |
| tryit.py a/b/c | Try It Yourself | calibration-set size, per-stratum numbers, loosening the gate |

Run `./make_outputs.sh`. Uses `fieldkit.evals` (book layer v3.3).

On site this code runs inside Caldwell's AWS account (us-east-1) under the gateway app identity `nl-eval`,
reading `s3://claims-eval/gold/`; its logs go to the log group `/caldwell/nl-eval/suite`, readable by the
`nl-shadow-readers` group and Anne Kessler.
