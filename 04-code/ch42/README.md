# Chapter 42 lab: the first ninety days

Deterministic stand-in for Pennant's first ninety days in production (production day 0 = engagement day 168)
and Caldwell's second-customer comparison. No model calls, no network. Every number the chapter quotes comes
from `output/`, regenerated by `./make_outputs.sh`.

| Script | What it shows |
|---|---|
| `replay.py v0\|v1` | the ninety-day replay: BRF-INV layout v2 on day 19; v0 monthly sample read by Northlight, v1 leading PSI on the fingerprint score plus a weekly scored sample read by Dana Whitaker, containment, re-calibration signed day 33 |
| `drill.py v0\|v2` | live-incident drill: 429 storm and reconciliation queue stall; runbook step by step; time to detect, acknowledge, mitigate |
| `deprecation.py v0\|v1` | failure injection: provider retires the EU pin during the peak-season change freeze |
| `ownership.py` | Chapter 41 readiness re-run on production evidence (0.40, 0.30, 0.80) and the ownership map |
| `livestable.py v0\|v1` | the ninety-day review as the Live Stable gate |
| `caldwell.py` | the second customer: a content drift that the fingerprint PSI cannot see |
| `tryit.py a\|b\|c` | Try It Yourself exercises |

Uses `fieldkit.liveops` (v5.1) and `fieldkit.handover` (v5). Package version stays 0.1.0.
